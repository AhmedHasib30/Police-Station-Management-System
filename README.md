# 🚔 Police Station Management System

A console-based **Police Station Management System** developed in C++ as a Data Structures and Algorithms project.

The system manages police officers and criminal records and demonstrates fundamental data structures, searching techniques, and sorting algorithms.

---

## 📌 Features

- 👮 View police officer records
- 🚨 View criminal records
- ➕ Add a police officer or criminal
- 🗑️ Delete a police officer or criminal
- 🔢 Sort police officers by ID
- 💰 Sort police officers by salary
- 🔤 Sort criminals by name
- 🔎 Search criminals by name
- 🔍 Search police officers by ID
- 📜 View operation history
- 🚪 Exit the application

---

## 🧠 Data Structures & Algorithms

### 🔄 Sorting Algorithms

- **Selection Sort** — Sort police officers by ID
- **Insertion Sort** — Sort police officers by salary
- **Bubble Sort** — Sort criminals by name

### 🔍 Searching Algorithms

- **Linear Search** — Search criminals by name
- **Binary Search** — Search police officers by ID

### 🧱 Data Structures

- **Vector** — Stores police officer and criminal records
- **Queue** — Implemented using a fixed-size array
- **Stack** — Used to maintain operation history

---

## 💻 Technologies

- **Language:** C++
- **Standard Library:** C++ STL
- **Concepts:** Data Structures & Algorithms, Searching, Sorting
